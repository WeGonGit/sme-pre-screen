# 🏦 SME RFT Pre-Screen Application

A web-based frontend application built to perform **pre-screening of SME loan applications**.  
The system captures business and financial details, verifies submitted documents, and displays eligibility decisions using a REST API backend.

This project demonstrates a real-world **banking workflow UI** built with modern React tooling and clean UX practices.

---

## 🚀 Features

✅ Loan pre-screening application form  
✅ Financial input validation  
✅ Document checklist verification (KYC, Income Proof, Business Proof)  
✅ REST API integration  
✅ Rule-based eligibility decision display  
✅ Dashboard view  
✅ Responsive UI  
✅ HDFC branding header and footer

---

## 🛠 Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- REST APIs (Node/Express or any compatible API server)
